# Site page images (production)

Place official photos here, then set in repo-root `.env`:

```
VITE_USE_LOCAL_SITE_IMAGES=true
```

Expected filenames:

- home-hero.jpg
- announcements.jpg
- blog.jpg
- contact.jpg
- family.jpg
- gallery.jpg
- videos.jpg

Or override individually with `VITE_IMAGE_HOME_HERO`, `VITE_IMAGE_BLOG`, etc.
